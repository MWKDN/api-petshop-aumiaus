# API Pet Shop AuMiaus 

Esta é uma API RESTful simples desenvolvida em Node.js com o framework Express.js, criada como exercício prático do curso da EBAC.

## Funcionalidades

- **`GET /`**: Retorna uma mensagem de boas-vindas da aplicação.
- **`GET /servicos`**: Lista todos os serviços disponíveis no pet shop em formato JSON.

## Tecnologias Utilizadas

- **Node.js**
- **Express.js**
