# API Pet Shop AuMiaus 

Esta é uma API RESTful simples desenvolvida em Node.js com o framework Express.js, criada como exercício prático do curso da EBAC.

## Funcionalidades

- **`GET /`**: Retorna uma mensagem de boas-vindas da aplicação.
- **`GET /servicos`**: Lista todos os serviços disponíveis no pet shop em formato JSON.

## Tecnologias Utilizadas

- **Node.js**
- **Express.js**

## Como executar o projeto localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/MWKDN/api-petshop-aumiaus.git

2. Instale as dependências:

```bash
npm install

3. Inicie o servidor:

```bash
node index.js

4. Acesse no seu navegador copiando e colando o link, ou digitando: http://localhost:3000/servicos
